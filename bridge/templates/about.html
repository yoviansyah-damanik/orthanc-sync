{{ app_name }}

Aplikasi jembatan (bridge) yang menghubungkan sistem informasi rumah sakit (SIMRS) dengan Orthanc PACS dan perangkat modality DICOM. Menangani sinkronisasi worklist, enkapsulasi dokumen medis, serta perutean dan transfer studi DICOM secara otomatis.

Modul Utama

Ringkasan fungsi setiap modul yang tersedia dalam aplikasi ini.

Worklist

Menerima data pemeriksaan dari SIMRS dan menerbitkannya sebagai berkas Modality Worklist (.wl) untuk alat pemeriksaan.

Modality DOC

Mengkonversi dokumen PDF/foto menjadi berkas DICOM Encapsulated Document dan menyimpannya di folder aplikasi.

DICOM Scanner

Memindai jaringan untuk menemukan dan memverifikasi konektivitas perangkat DICOM (C-ECHO).

DICOM Router

Meneruskan studi baru di Orthanc secara otomatis ke perangkat tujuan berdasarkan aturan perutean.

Scheduled Backup

Menjadwalkan pengiriman berkala studi dari Orthanc ke perangkat cadangan (backup) tertentu.

API Log & Manajemen API

Mencatat setiap request API masuk dan mengelola API Key untuk integrasi eksternal (SIMRS).

Teknologi yang Digunakan

Django (Python) MySQL Orthanc PACS Server pydicom pynetdicom Tailwind CSS
