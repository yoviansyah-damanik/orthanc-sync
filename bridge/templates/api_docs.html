Tutorial Pengujian API Menggunakan Postman

Petunjuk langkah demi langkah menguji seluruh endpoint REST API Orthanc Bridge menggunakan Postman Collection resmi.

Unduh Collection (.json) Unduh Environment (.json)
1

Impor Berkas JSON

Unduh `orthanc_bridge_postman_collection.json` di atas. Di aplikasi Postman, klik **Import** lalu pilih berkas tersebut.

2

Setel Variable `apiKey`

Buka tab **Variables** pada koleksi, isi `baseUrl` (`http://localhost:9123`) dan `apiKey` dengan Kunci API dari menu **Manajemen API**.

3

Uji Worklist & DOC

Jalankan `POST /api/worklist` untuk registrasi DICOM Worklist, atau `POST /api/doc/upload` untuk mengunggah PDF ke Modality DOC.

4

Pantau di API Log

Buka menu **API Log** untuk memantau status respon (Success 200, Duplicate 409, atau Error) secara real-time.

POST / PUT

Create or Update DICOM Worklist

Kirim data pasien dan detail pemeriksaan PACS ke endpoint ini. Sistem akan menghasilkan file .wl secara fisik di folder DICOM Worklist server dan mencatatnya ke database lokal.

Catatan Penting: Gunakan metode POST untuk membuat data baru. Gunakan metode PUT atau sematkan parameter JSON "bypass": true jika ingin secara paksa menimpa data pemeriksaan yang sudah ada.

JSON Body Parameters

Field Type Description
accession_number* string(16) ID unik pemeriksaan. Maksimal 16 karakter (Standar batas DICOM).
patient_name* string Nama Pasien. Otomatis diformat menjadi standar DICOM (Family^Given).
patient_id string ID Medis Pasien / No RM (Rekam Medis).
modality string Kode DICOM Modality (misal: CT, CR, DX, MR, US).
scheduled_date string(date) Tanggal pemeriksaan, format: YYYY-MM-DD.
webhook_url string(url) Optional callback webhook. Orthanc Bridge akan memanggil URL ini saat study selesai.

Upload & Encapsulate Modality DOC

Mengirimkan dokumen (PDF / Foto Medis) untuk di-enkapsulasi menjadi berkas standar DICOM Modality DOC secara terotomatisasi. Mendukung pengiriman berkas via multipart form-data maupun payload JSON dengan file berformat base64.

/api/doc/upload

Payload Fields (JSON / Form Data)

Field Tipe Data Deskripsi
accession_number * string (required) Nomor aksesi unik (cth: ACSN-DOC-001). Tidak boleh duplikat.
patient_id * string (required) Nomor rekam medis pasien.
patient_name * string (required) Nama lengkap pasien.
procedure_desc string Judul / deskripsi dokumen medis.
file_b64 / file * file / string File PDF/JPG (multipart) atau Base64 string (JSON).
send_to_pacs boolean Kirim otomatis hasil DICOM ke server PACS (default: true).

Contoh Implementasi Lengkap (PHP & cURL)

Berikut adalah templat integrasi siap pakai menggunakan PHP Native dan ekstensi cURL untuk mengirim payload DICOM Worklist secara aman ke server. 

<?php
// 1. Susun payload data pemeriksaan pasien
$payload = [
    "accession_number" => "TEST-2026-001",
    "patient_id" => "RM-99201",
    "patient_name" => "JOHN DOE",
    "modality" => "CT",
    "scheduled_date" => date('Y-m-d')
];

// 2. Inisiasi cURL ke Orthanc Bridge
$ch = curl_init("http://{{ request.get_host }}/api/worklist");
curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode($payload));
curl_setopt($ch, CURLOPT_HTTPHEADER, [
    'Content-Type: application/json',
    'X-API-Key: {your_key_here}'
]);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);

// 3. Jalankan request
$response = curl_exec($ch);
curl_close($ch);

// 4. Tampilkan status response
echo $response;
?>
